### Download
| System | Datei |
|---|---|
| **Windows** 10/11 | `Open-Game-Launcher.exe` (ARM: `Open-Game-Launcher-arm64.exe`) → Doppelklick → „Installieren“. `MAZ-Launcher.exe` ist dieselbe Datei unter dem alten Namen – nur damit ältere Versionen sich selbst updaten können. |
| **macOS** 11+ (Apple Silicon + Intel) | `Open-Game-Launcher-…-macOS.dmg` → in „Programme“ ziehen → beim ersten Mal Rechtsklick → „Öffnen“ |
| **Linux** (x86_64 / ARM64) | AppImage, `.deb`, `.rpm`, `.pkg.tar.zst` (Pacman), Flatpak oder Snap – siehe README |

Schon installiert? Der Launcher meldet das Update selbst – einfach auf „Jetzt updaten“ klicken.

Alle Prüfsummen stehen in `SHA256SUMS.txt`. Webseite: https://mikeadamrgb.github.io/Open-Game-Launcher/ · Alle Änderungen: [CHANGELOG.md](https://github.com/MikeAdamRGB/Open-Game-Launcher/blob/main/CHANGELOG.md)

Windows zeigt „Der Computer wurde durch Windows geschützt“? → „Weitere Informationen“ → „Trotzdem ausführen“.
