## MAZ Launcher 1.4.0 🐧🍎🧱

Jetzt für **Windows, macOS und Linux** – und alles läuft lokal.

### Download
| System | Datei |
|---|---|
| **Windows** 10/11 | `MAZ-Launcher.exe` (ARM: `MAZ-Launcher-arm64.exe`) → Doppelklick → „Installieren“ |
| **macOS** 11+ (Apple Silicon + Intel) | `MAZ-Launcher-…-macOS.dmg` → in „Programme“ ziehen → beim ersten Mal Rechtsklick → „Öffnen“ |
| **Linux** (x86_64 / ARM64) | AppImage, `.deb`, `.rpm`, `.pkg.tar.zst` (Pacman), Flatpak oder Snap – siehe Tabelle im README |

Alle Prüfsummen stehen in `SHA256SUMS.txt`. Webseite: https://mikeadamrgb.github.io/MAZ-Lauchner/

### Neu in 1.4.0
- **Linux und macOS:** Steam (auch Flatpak/Snap-Steam), Epic (macOS: Epic Games Launcher, Linux: Heroic), eigene Spiele (Linux: auch .exe über Wine).
- **Roblox:** Roblox wird erkannt und gestartet. Füg Links deiner Lieblings-Roblox-Spiele hinzu – jedes wird eine eigene Kachel, die direkt ins Spiel startet (Linux: über Sober).
- **Updates in der App:** Hinweis bei neuer Version und Knopf „Jetzt updaten“ – Download wird per SHA256 geprüft und passend zur Installation eingespielt.
- **Alles lokal:** Konto, Freunde und Chat wurden entfernt. Kein MAZ-Server mehr, kein Konto nötig.
- **ARM64** für Windows und Linux.

Windows zeigt „Der Computer wurde durch Windows geschützt“? → „Weitere Informationen“ → „Trotzdem ausführen“.
