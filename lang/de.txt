p.drive_missing.title = Laufwerk {drive} nicht gefunden
p.drive_missing.what = „{game}“ liegt auf dem Laufwerk {drive}. Dieses Laufwerk ist gerade nicht da.
p.drive_missing.why = Meistens ist eine externe Festplatte oder ein USB-Stick nicht eingesteckt, oder das Laufwerk hat einen anderen Buchstaben bekommen.
p.drive_missing.steps = Steck die externe Festplatte oder den USB-Stick ein, auf dem das Spiel liegt.\nWarte ein paar Sekunden, bis Windows das Laufwerk erkannt hat (es taucht dann im Explorer unter „Dieser PC“ auf).\nKlick hier im Launcher noch einmal auf „Spielen“.\nHat das Laufwerk jetzt einen anderen Buchstaben (z. B. E: statt D:)? Dann klick auf „Spiel bearbeiten“ und wähle die EXE-Datei neu aus.

p.exe_missing.title = Spieldatei nicht gefunden
p.exe_missing.what = Der Launcher wollte „{game}“ starten, aber die Datei gibt es an diesem Ort nicht mehr.
p.exe_missing.why = Das Spiel wurde wahrscheinlich verschoben, umbenannt, gelöscht oder neu installiert. Manchmal entfernt auch ein Antivirus-Programm die Datei.
p.exe_missing.steps = Klick unten auf „Spiel bearbeiten“.\nKlick neben „Programm“ auf „Durchsuchen…“.\nSuch den Ordner, in dem das Spiel jetzt liegt, und wähle die Start-Datei aus (meistens heißt sie wie das Spiel und endet auf .exe).\nKlick auf „Speichern“ und dann wieder auf „Spielen“.\nFindest du die Datei gar nicht mehr? Dann installiere das Spiel neu und wiederhole die Schritte.\nHat dein Antivirus die Datei gelöscht? Schau in der Quarantäne deines Antivirus-Programms nach und stelle sie wieder her (nur wenn du dem Spiel vertraust).

p.workdir_missing.what = Für „{game}“ ist ein Arbeitsordner eingestellt, den es nicht gibt.
p.workdir_missing.why = Der Ordner wurde verschoben oder gelöscht.
p.workdir_missing.steps = Klick auf „Spiel bearbeiten“.\nLösche den Text im Feld „Arbeitsordner“ (leer lassen ist völlig okay – dann nimmt der Launcher automatisch den Ordner der EXE).\nKlick auf „Speichern“ und starte das Spiel erneut.

p.admin_required.title = Das Spiel braucht Administratorrechte
p.admin_required.what = „{game}“ möchte mit Administratorrechten gestartet werden.
p.admin_required.why = Manche Spiele (oder ihre Anti-Cheat-Programme) brauchen mehr Rechte, damit sie funktionieren. Das ist normal.
p.admin_required.steps = Klick unten auf „Als Administrator starten“.\nWindows fragt dann „Möchten Sie zulassen, dass…“ – klick auf „Ja“.\nDamit du das nicht jedes Mal machen musst: Klick auf „Spiel bearbeiten“ und schalte „Immer als Administrator starten“ ein.

p.access_denied.title = Zugriff verweigert
p.access_denied.what = Windows hat den Start von „{game}“ nicht erlaubt.
p.access_denied.why = Entweder fehlen Rechte für den Ordner, die Datei ist durch Windows gesperrt (heruntergeladene Datei), oder ein Antivirus-Programm blockiert sie.
p.access_denied.steps = Probier zuerst „Als Administrator starten“ (unten). Windows fragt nach – klick auf „Ja“.\nKlappt das nicht: Öffne den Spielordner (Knopf unten), klick mit der rechten Maustaste auf die EXE-Datei → „Eigenschaften“.\nGanz unten im Reiter „Allgemein“ steht vielleicht „Zulassen“ oder „Blockierung aufheben“. Setz dort den Haken und klick auf „OK“.\nImmer noch nicht? Öffne dein Antivirus-Programm und schau, ob es die Datei blockiert hat. Wenn du dem Spiel vertraust, füge es dort als Ausnahme hinzu.\nLiegt das Spiel in „C:\Programme“? Dann hilft es oft, das Spiel in einen eigenen Ordner wie „C:\Spiele“ zu installieren.

p.not_an_app.title = Das ist keine Spiel-Datei
p.not_an_app.what = Die ausgewählte Datei für „{game}“ kann von Windows nicht als Programm gestartet werden.
p.not_an_app.why = Wahrscheinlich wurde die falsche Datei ausgewählt, die Datei ist kaputt (z. B. unvollständiger Download), oder das Spiel ist für ein anderes System gemacht.
p.not_an_app.steps = Klick auf „Spiel bearbeiten“.\nKlick auf „Durchsuchen…“ und wähle die richtige Start-Datei. Sie endet auf „.exe“ und heißt meistens wie das Spiel – nicht „unins000.exe“, „setup.exe“ oder „UnityCrashHandler.exe“.\nSpeichern und erneut starten.\nIst die Datei kaputt? Dann lade bzw. installiere das Spiel noch einmal neu.
